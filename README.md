# Cheburcheck Watchdog

Служба для Ubuntu и Debian, которая проверяет домены и публичные IPv4 и IPv6. Результаты проверок попадают в журнал systemd и могут автоматически отправляться в Telegram. [Документация API Cheburcheck](https://cheburcheck.ru/kb/api).

Автор: github.com/obkaiter

При поддержке BITWIRE.ME

## Установка

Нужны Ubuntu 22.04+ или Debian 11+ с работающим systemd, права `sudo` и доступ к GitHub и `cheburcheck.ru`. Установщик и команда управления устанавливают недостающие зависимости через `apt-get`.

```bash
curl -fsSL https://raw.githubusercontent.com/obkaiter/cheburcheck-watchdog/main/install.sh | sudo bash
sudo cheburcheck-watchdog
```

Для установки из локальной копии репозитория выполните `sudo bash ./install.sh --local` из её каталога. Установка регистрирует службу в systemd. Первый запуск службы выполняется из меню после настройки.

## Управление

Откройте `sudo cheburcheck-watchdog` в интерактивном терминале. Используйте стрелки ↑ и ↓ и Enter. В главном меню также можно набрать номер пункта и нажать Enter. Статус службы обновляется по данным systemd.

1. **Запустить**. Подтвердите запуск клавишей Enter. При необходимости меню предложит ввести токен Cheburcheck и пополнить список проверок. Watchdog начнёт проверку сразу и будет запускаться при загрузке сервера.
2. **Остановить**. Подтвердите действие клавишей Enter. Запущенная службой проверка прервётся, расписание остановится, автозапуск отключится.
3. **API-токен cheburcheck.ru**. Введите токен Cheburcheck для публичных сканеров. Символы при вводе скрыты.
4. **Отчёты в Telegram**. Настройте бота, чат и тему при необходимости. Здесь же можно отправить тестовое сообщение или отключить отчёты.
5. **Проверяемые IP и домены**. Добавьте публичный IPv4, IPv6 или полное доменное имя, например `example.com` или `пример.рф`. Для удаления выберите запись в списке. Удаление последней записи останавливает службу и отключает автозапуск.
6. **Период проверки**. Доступны интервалы в 1, 3, 6, 12, 24 и 48 часов, а также неделя. По умолчанию — 6 часов.
7. **Разовая проверка**. Выберите один сохранённый домен или все домены и подтвердите отправку отчёта в настроенный чат Telegram. Для разовой проверки запускать службу не требуется. Если проверка уже идёт, меню предложит повторить попытку после её завершения.
8. **Удалить Cheburcheck Watchdog**. Удаляет службу, команду, файлы приложения и настройки, включая оба токена. Существующие записи хранятся по правилам журнала systemd.
9. **Выход**. Закрывает меню.

Изменения настроек сразу применяются к работающей службе. Её перезапуск начинает новый цикл проверок.

## Отчёты в Telegram

1. Создайте бота через [@BotFather](https://t.me/BotFather). Для личного чата откройте бота и нажмите **Start**. Для группы или канала добавьте бота и дайте ему право отправлять сообщения.
2. В меню **Отчёты в Telegram → Настроить бота и чат** введите токен бота и числовой `Chat ID`. У публичной супергруппы или канала также можно указать `@username`. Числовой ID доступен в поле `chat.id` входящего обновления бота. [Telegram Bot API](https://core.telegram.org/bots/api#getupdates).
3. Для темы в группе с включёнными темами укажите её числовой `Topic ID`. Например, для ссылки на тему `t.me/c/1234567890/13809` укажите `Chat ID` `-1001234567890` и `Topic ID` `13809`. Для обычной отправки в чат пропустите поле. При редактировании Enter сохраняет выбранную тему, `0` сбрасывает её, а `1` обозначает тему «Общее». При смене чата укажите тему заново. [Ссылки на темы Telegram](https://core.telegram.org/api/links#forum-topic-links).
4. Выберите **Отправить тестовое сообщение** и проверьте доставку в выбранное место. Разовые и автоматические отчёты отправляются туда же.

Watchdog отправляет отчёт после каждого автоматического цикла и после разовой проверки. Автоматический цикл включает и IP-адреса, и домены. Отчёт содержит время UTC, результаты по спискам, ответы сканеров и ошибки. При большом числе записей отчёт делится на несколько сообщений. Если Telegram недоступен, служба записывает ошибку в журнал и продолжает проверки по расписанию.

Пример отчёта:

```text
🛡 Cheburcheck Watchdog
🕒 Проверка по расписанию · 21.11.2026 18:00 UTC
🔎 Целей обработано: 1 из 1

🌐 example.com
✅ По спискам: блокировка не найдена
⚠️ Сканеры: 2 из 3, из кеша: 1. доступен: 2 (неполный результат)
```

## Проверки и журнал

Для каждого IP или домена Watchdog сначала запрашивает `/check`, а затем использует выданный контекст для `/probe/<id>`. Ответы сканеров собираются до события `done`. В журнале отдельно отмечаются неполные результаты и повторно использованные измерения. По документации Cheburcheck стандартный кеш измерений действует три часа.

Цели в цикле проверяются последовательно с паузой в 5 секунд. Следующий автоматический цикл начинается через выбранный интервал после завершения текущего. При HTTP 429 текущий цикл прерывается. Если заголовок `Retry-After` требует более долгой паузы, используется указанное API время.

```bash
sudo journalctl -u cheburcheck-watchdog.service -n 100
sudo journalctl -u cheburcheck-watchdog.service -f
```

## Автообновление

При открытии меню Watchdog читает `VERSION` в выбранной ветке GitHub. Если версия выше установленной, Watchdog скачивает архив ветки, проверяет версию и обязательные файлы, устанавливает обновление и заново открывает меню. Работающая служба перезапускается, чтобы подхватить новый код. Настройки и токены хранятся отдельно. При сбое проверки или загрузки открывается установленная версия.

Пропустить проверку обновлений для одного запуска можно так:

```bash
sudo CHEBURCHECK_WATCHDOG_SKIP_UPDATE=1 cheburcheck-watchdog
```

Установщик и автообновление используют `CHEBURCHECK_WATCHDOG_BRANCH`. По умолчанию выбрана ветка `main`. Для другой ветки задавайте переменную и при установке, и при последующих запусках `cheburcheck-watchdog`.

## Файлы

| Путь | Назначение |
| --- | --- |
| `/opt/cheburcheck-watchdog/` | Файлы установленного приложения |
| `/usr/local/bin/cheburcheck-watchdog` | Команда управления |
| `/etc/systemd/system/cheburcheck-watchdog.service` | Юнит systemd |
| `/etc/cheburcheck-watchdog/config.json` | Токены, чат и тема Telegram, список проверок и период, файл с правами `0600` |
| `/run/cheburcheck-watchdog/` | Временный каталог для координации разовой проверки и расписания |
